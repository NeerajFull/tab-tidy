Privacy policy

Last updated 5 October 2026

Tab Tidy is a browser extension that groups tabs, closes duplicate tabs, and saves sessions. This page says what data Tab Tidy uses, where the data goes, and how to remove it.

Summary

  • There is no Tab Tidy server. The developer does not receive any of your data.
  • Without an Anthropic API key, no data leaves your browser.
  • With your own API key, a short list of open tabs goes to Anthropic after each tidy.
  • Tab Tidy does not use analytics, tracking or advertising.

Data stored on your device

Tab Tidy stores this data in the extension storage of your browser profile:

  • Your settings, such as the idle time for sleeping tabs.
  • Your Anthropic API key, if you add one.
  • The grouping rules that Tab Tidy learns when you drag tabs between groups.
  • Your saved sessions: the tab addresses, titles and group names of the windows you save.

This data stays in your browser profile. It is not synced to other devices. To remove it, delete the rules or sessions in Settings, or remove the extension.

Data sent to Anthropic

This section applies only if you add your own Anthropic API key in Settings. After each tidy, Tab Tidy sends one request from your browser directly to api.anthropic.com, so that Claude can move related tabs into the same group. The request contains:

  • The first 80 characters of each tab title.
  • The site name and the first 60 characters of the path of each tab. Query strings and #fragments are not sent.
  • The names of the tab groups.

The request is billed to your API key. Anthropic handles this data under its own terms and privacy policy. To stop sending data, delete the key in Settings.

Incognito and private windows are never included.

Permissions

  • tabs: to read tab addresses and titles, and to close duplicate tabs.
  • tabGroups: to create and name tab groups.
  • storage: to keep your settings, rules and sessions.

Tab Tidy does not ask for access to the content of web pages.

Changes and contact

Changes to this policy are published on this page and in the source code repository. For questions, open an issue on GitHub.
