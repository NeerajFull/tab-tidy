Tidy every tab in one click.

Tab Tidy groups your tabs by site, closes duplicates, and saves sessions you can open again later. You can undo every action.

What it does

Click the icon or press Alt+Shift+G. Every window is tidied in a few milliseconds.

Groups by site

One named group per site, such as GitHub, Figma or youtube.com. Jira and Confluence share one Atlassian group.

Staging joins live

Tabs on staging, dev or QA copies of a site go into the same group as the live site.

Closes duplicates

Finds the same page open twice, in any window, and closes the extra copy. Tracking parameters are ignored.

Learns your moves

Drag a tab into another site's group once. Tab Tidy remembers it and puts that site there every time.

Saves sessions

Save the tabs and groups of a window under a name. Open them again in a new window when you need them.

Optional Claude check

Add your own Anthropic API key, and Claude moves related tabs into the right group. Without a key, nothing leaves the browser.

Install

Takes about a minute.

Tab Tidy is not in the browser extension stores yet, so you install it in developer mode. It does not update automatically. To get a new version, come back to this page.

  1. Download tab-tidy-chrome.zip.
  2. Unzip it, and move the tab-tidy-chrome folder to a place where it can stay, such as Documents. Chrome loads the extension from this folder. If you delete the folder, the extension stops working.
  3. Open chrome://extensions in a new tab.
  4. Turn on Developer mode in the top-right corner.
  5. Click Load unpacked and select the tab-tidy-chrome folder.
  6. Click the puzzle icon in the toolbar and pin Tab Tidy.
  1. Download tab-tidy-edge.zip.
  2. Unzip it, and move the tab-tidy-edge folder to a place where it can stay, such as Documents. Edge loads the extension from this folder. If you delete the folder, the extension stops working.
  3. Open edge://extensions in a new tab.
  4. Turn on Developer mode in the left sidebar.
  5. Click Load unpacked and select the tab-tidy-edge folder.
  6. Click the puzzle icon in the toolbar and show Tab Tidy.

Firefox 139 or later. Firefox only keeps unsigned add-ons until it restarts, so you must load Tab Tidy again after each restart.

  1. Download tab-tidy-firefox.zip. Do not unzip it.
  2. Open about:debugging#/runtime/this-firefox in a new tab.
  3. Click Load Temporary Add-on and select tab-tidy-firefox.zip.

Update to a new version

Download the new zip. In Chrome or Edge, replace the files in your existing folder with the new ones, then click the reload icon on the Tab Tidy card in the extensions page. Keep the same folder, so your settings, rules and saved sessions stay.

Privacy

There is no Tab Tidy server.

  • Without an API key, nothing leaves your browser.
  • With your own Anthropic API key, short tab titles, site paths and group names go straight from your browser to Anthropic. Query strings are removed first.
  • Your key, rules and saved sessions stay on your device. They are not synced.
